# Space Invaders на C + Win32 API

Классическая игра Space Invaders, написанная с нуля на чистом C с использованием Win32 API.  
Семестровая работа по системному программированию.

---

## Про игру

Обычный Space Invaders — стреляешь по пришельцам, они спускаются вниз и стреляют в ответ.  
Есть барьеры, за которыми можно прятаться (пока их не разрушат).

**10 уровней**, на каждом враги становятся быстрее и умнее:

- **Уровни 1-3**: враги тупо стреляют вниз
- **Уровни 4-6**: целятся в тебя (в момент выстрела)
- **Уровни 7-10**: пули медленно поворачивают за тобой (самонаведение)

Плюс иногда пролетает UFO — если попадёшь, дадут случайное количество очков (50-300).

## Очки

- Нижние враги (красные) — **10**
- Средние (жёлтые) — **20**
- Верхние (синие) — **30**
- UFO — **50-300** (рандом)

---

## Бонусы (Power-Ups)

При убийстве врагов **с шансом 8%** выпадает шар-усиление. Лови его!

| Иконка | Что даёт |
|--------|----------|
| **+1** (красный) | +1 жизнь |
| **SH** (синий) | Щит на 12 секунд |
| **SL** (фиолетовый) | Замедление врагов на 8с |
| **FS** (жёлтый) | Быстрая стрельба на 10с |
| **3X** (мятный) | Тройной выстрел на 10с |
| **BM** (оранжевый) | Взрывные пули на 10с |

Активные бонусы показываются в правом верхнем углу с таймером.

## Как это работает

**Игровой цикл:**
- Фиксированный шаг 1/60 секунды (не через Sleep, а через QueryPerformanceCounter)
- Логика обновляется строго 60 раз в секунду
- Рисование — когда успеет

**Рисование:**
- Двойная буферизация (рисую в невидимый буфер, потом копирую на экран одним BitBlt)
- Никаких .bmp файлов — всё рисуется прямоугольниками через GDI

**Враги:**
- Двигаются все вместе (как в оригинале)
- Когда касаются края — спускаются вниз и меняют направление
- Чем меньше врагов осталось — тем быстрее они двигаются
- Стреляет случайный враг из нижнего ряда каждой колонки

**Самонаведение (уровни 7-10):**
- Пуля медленно поворачивает угол в сторону игрока
- Скорость поворота ограничена (можно увернуться)

## Как собрать

Нужен **GCC** (MinGW).

### Самый простой способ:

```batch
build.bat
```

Всё скомпилирует и запустит.

### Из VS Code:

1. Открыть папку проекта
2. Поставить расширение C/C++ (от Microsoft)
3. Нажать `Ctrl+Shift+B`

### Вручную из консоли:

```bash
gcc -std=c11 -O2 -Wall -mwindows ^
    src/main.c src/game.c src/render.c src/input.c src/levels.c ^
    -o space_invaders.exe ^
    -lgdi32 -lmsimg32 -lwinmm -lm
```

### Через CMake:

```bash
mkdir build
cd build
cmake .. -G "MinGW Makefiles"
mingw32-make
```

## Технические детали

- **Язык:** чистый C (C11), без всякого C++
- **Библиотеки:** только стандартные Windows API (GDI для рисования)
- **Память:** всё статически, никакого malloc
- **Утечек нет** — все GDI объекты удаляются в конце

**Как устроен цикл:**

```c
while (игра работает) {
    // Обработать события Windows
    // Посчитать delta time
    // Обновить логику (фиксированный шаг)
    // Нарисовать всё в буфер
    // Скопировать буфер на экран
}
```

**Коллизии:**
- Простые AABB (прямоугольники)
- Проверяются пули vs враги, пули vs игрок, пули vs барьеры

**Хай-скор:**
- Сохраняется в `hiscore.dat` (бинарный файл)
- Автоматически загружается при запуске

## Если не компилируется

1. Проверь что GCC установлен: `gcc --version`
2. Убедись что MinGW в PATH
3. Попробуй `build.bat` — там всё прописано

Если всё равно не работает — скорее всего путь к GCC кривой, пропиши его в `.vscode/c_cpp_properties.json`.
